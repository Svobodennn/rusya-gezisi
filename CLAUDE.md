# Rusya Gezisi — project rules

Offline trip page (PWA) for Moscow and St Petersburg, 19 Dec 2026 – 14 Jan 2027. Product truth: `PRODUCT.md`.
Visual system: `DESIGN.md`. The structure below was settled on 2026-09-30; keep it — do not reorganise it again.

## Layout

```
app/                 deploy root, served as-is (no build step, no bundler, no npm)
  index.html         shell only: head, region containers, one <script type="module" src="js/main.js">
  sprite.svg         every pattern, ornament symbol and icon; injected inline at start-up (js/lib/sprite.js)
  sw.js              GENERATED by tools/build_sw.py — never edit by hand; stays at the root for its scope
  data/ fonts/ icons/ img/   data pipelines write these paths; do not move them
  css/base/          tokens → base → layout (… components, theme …) → motion (loaded last)
  css/components/    one file per component, named after it
  css/theme/         textile (page pattern), glass (.glass utility class), folk-shelf (matryoshka shelf)
  js/main.js         composition root: load, build the store and page, wire events and the clock
  js/lib/            tiny browser helpers (svg, motion preference, sprite)
  js/core/           trip logic — PURE: no DOM, no storage, no browser APIs
  js/state/          store (frozen snapshot, set(patch) only), ticks (localStorage), url (?now=, #gun-N), load
  js/views/          HTML string builders — PURE: data in, markup out, everything escaped with esc/ruText
  js/map/            route map: geometry, detail (level of detail, name layout) and names (name data) are pure;
                     layers, base-map, labels (name nodes), pins, camera, interaction, route-map are DOM
  js/effects/        hero weather: snow, street lights
  js/ui/             DOM controllers: page (render orchestration), regions, actions (click table), focus, panels…
  js/pwa/            service worker registration and the offline status line
tests/js/            node tests for core, state, views and map (outside app/ so they are never deployed)
tools/               Python build scripts; tools/osm/ is the base-map package behind tools/build_maps.py
```

**Layer rule (one-way):** `lib`, `core` ← `state`, `views` ← `map`, `effects`, `pwa` ← `ui` ← `main`. A lower layer never
imports a higher one. Modules have no side effects on import except `main.js`. Named exports only.

## Rules

- No inline `style=""` or `<style>`: the CSP forbids them. Set CSS custom properties through CSSOM instead.
- Every data string reaches `innerHTML` through `esc()` or `ruText()`, every URL through `safeUrl()`.
- Cyrillic text must carry `lang="ru"` (`ruText` does it), or Sofia Sans draws Bulgarian letterforms.
- JS modules stay under 200 lines, CSS files under 250. Split by responsibility, not by line count.
- A new CSS file is linked in `index.html` in cascade order; a new asset type needs its suffix in `tools/build_sw.py`.

## Commands

```bash
node --test "tests/**/*.test.mjs" tools/sw.test.mjs      # JS unit tests
python3 -m unittest discover -s tools -p 'test_*.py'      # Python tests
python3 tools/build_trip.py      # plan + places → app/data/trip.json and app/img (needs the local photos)
python3 tools/build_heroes.py    # day covers → app/img/hero-*.webp, app/data/heroes.json
python3 tools/build_maps.py --offline   # base maps from tools/osm-cache (drop --offline to fetch from Overpass)
python3 tools/build_memories.py  # hatiralar/<YYYY-MM-DD>/*.jpg → app/memories + app/data/memories.json (EXIF/GPS stripped)
python3 tools/build_sw.py        # after ANY change in app/: new file hashes → incremental offline update
python3 tools/check_app.py       # Playwright: offline behaviour, 20 checks, review screenshots
python3 tools/check_visual.py    # pixel-exact diff against .impeccable/baseline (--baseline to re-capture)
python3 -m http.server 8000 -d app   # local preview; ?now=2026-12-20T13:00:00Z freezes the trip clock
```

Photographs are third-party (rights stay with their owners): `app/img/` and `mekanlar/**/*.jpg` are not committed.
Memories: the originals in `hatiralar/` never leave the computer (gitignored, they carry GPS); only the cleaned WebP
copies in `app/memories/` are committed — and in this public repository they are public.
